# Smiling your way to happiness or misery? Experimental tests of competing perspectives

Authors: Nicholas A. Coles, Annabel Dang, and Joao Francisco Goes Braga Takayanagi

This repository contains the data, code, materials, and manuscript for a pre-registered experiment testing whether posed smiles improve or worsen mood depending on emotional context, repetition, and threat of punishment. The most important files are `smile25b_process_data.R` (builds the analysis dataset), `smile25b_main_analysis.R` (runs the main analyses and figures), and `writing/smile_R3_writing.qmd` (the manuscript). Everything else is listed below.

## Repository structure

- `smile.Rproj` — RStudio project file.

- `smile25b_process_data.R` — Cleans the raw Gorilla/Prolific exports into the analysis-ready dataset.

- `smile25b_run_openface.R` — Runs OpenFace on participants' recorded videos to extract facial Action Unit (AU12) activity.

- `smile25b_compile_openface.R` — Aggregates the per-frame OpenFace output into per-participant smile-compliance scores.

- `smile25b_main_analysis.R` — Runs the primary confirmatory analyses and sensitivity checks, and generates the main manuscript figures.

- `smile25b_secondary_analysis.R` — Runs the secondary outcome analyses (life satisfaction, burnout, fear, anger) and generates their figure.

- `smile25b_functions.R` — Shared plotting and Bayesian-analysis helper functions used by the analysis scripts.

- `data/` — Raw and processed data, plus cached statistical results.

  - `smile25b_raw_data.csv` — Unprocessed merged export from Gorilla/Prolific.
  - `smile25b_processed_data.csv` — Cleaned, analysis-ready dataset (one row per participant).
  - `smile25b_openface_processed.csv` — Per-participant OpenFace smile-compliance scores.
  - `smile25b_awareness_check_pending.csv` / `smile25b_awareness_check_completed.csv` — Coder tracking sheets for the funnel debriefing review.
  - `main_analysis/`, `secondary_analysis/` — Cached model/statistics objects (`.Rds`) exported by the analysis scripts and read into the manuscript at render time.
  - `gorilla_survey/` (not included; gitignored) — Raw per-participant video recordings and task exports referenced by `smile25b_run_openface.R`.

- `figures/` — Manuscript figures generated by the analysis scripts.

  - `smile25b_happy_plot.jpg` — Primary results figure.
  - `smile25b_combined_secondary_plot.jpg` — Secondary outcomes figure (life satisfaction, burnout, fear, anger).
  - `smile25b_sens_plot.jpg` — Sensitivity check figure (weak smiles included vs. excluded).

- `materials/` — Study materials used to run the experiment.

  - `Gorilla task spreadsheets/` — Task configuration files for the single- vs. ten-repetition posing conditions.
  - `Images/` — Positive and negative stimulus images shown during the study.
  - `IRB/` — Consent form, debriefing script, survey script, and protocol approved by the IRB.

- `power simulation/` — Power simulation used to justify the sample size.

  - `smile_power_simulation.Rmd` — Simulates power for the main effect and two-/three-way interactions.
  - `pwr_sim_main.Rds`, `pwr_sim_twoway.Rds`, `pwr_sim_threeway.Rds`, `DF.l.full.rds` — Cached simulation outputs.
  - `pwr_sim_plot.png` — Summary plot of the power simulation.

- `writing/` — Manuscript source files and rendered outputs.

  - `smile_R3_writing.qmd` — Quarto source for the main manuscript (renders to PDF).
  - `smile_R3_writing.pdf` — Rendered manuscript.
  - `smile_R3_SI.qmd` / `smile_R3_SI.docx` — Quarto source and rendered Word document for the Supplemental Materials.
  - `references.bib` — Bibliography file cited in the manuscript.
  - `_extensions/` — The apaquarto Quarto extension used to format the manuscript in APA style.
